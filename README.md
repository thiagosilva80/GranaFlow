
💰 GranaFlow

O GranaFlow é uma aplicação web de organização financeira pessoal desenvolvida para facilitar o controle de receitas, despesas e metas financeiras.

O projeto foi criado com o objetivo de colocar em prática conhecimentos de desenvolvimento web, Python, Flask, banco de dados e operações CRUD, construindo uma aplicação completa desde a interface até o back-end.

🚀 Funcionalidades
🔐 Cadastro e autenticação de usuários
💰 Registro de receitas
💸 Registro de despesas
📊 Dashboard financeiro
🎯 Criação e acompanhamento de metas financeiras
📋 Histórico de movimentações
✏️ Gerenciamento de informações financeiras
👤 Dados separados por usuário

💡 Objetivo do projeto

O GranaFlow foi desenvolvido como um projeto de portfólio para aplicar conceitos estudados em Análise e Desenvolvimento de Sistemas, principalmente desenvolvimento back-end, integração com banco de dados, autenticação de usuários, lógica de programação e construção de interfaces web.

Além da parte técnica, o projeto busca resolver um problema real: tornar o acompanhamento das finanças pessoais mais simples e organizado.
